# Changelog

## 1.0.0 — 2026-08-16

First portfolio release of MatchStream.

- Canonical StatsBomb ingestion, deterministic replay, and versioned Redpanda
  contracts.
- Durable PostgreSQL projections, idempotent redelivery, retry/DLQ handling,
  canonical history, rebuild, observability, FastAPI/WebSocket API, and React
  dashboard.
- Local benchmark/reliability tooling, observed reports, France–Argentina real
  match demo instructions, system design, limitations, and interview notes.
